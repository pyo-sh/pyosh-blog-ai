# A-01: 접근성 공통 체크리스트

**상태:** SPEC
**최종 수정:** 2026-03-20

> **전체 클라이언트 기능 구현 완료 후 정확한 스펙 명시 예정. 그 전에 이 문서 기반으로 구현하지 않는다.**
> 현재는 개발 시 참고할 원칙만 정의한다. 구현 완료 후 컴포넌트별 구체적 체크 항목, 키보드 탭 순서 검증, 스크린 리더 테스트, addon-a11y 결과 기반 수정 사항을 추가한다.

---

## 접근성 원칙

### 네비게이션

- Skip-to-content 링크를 제공한다
- 시맨틱 HTML 요소를 사용한다 (`<nav>`, `<main>`, `<aside>`, `<footer>`, `<article>`, `<section>`)
- 활성 페이지/항목에 `aria-current="page"`를 표시한다

### 포커스 관리

- 모달은 focus trap을 적용하고, 닫힐 때 이전 요소로 focus를 복원한다
- 키보드로 모든 인터랙티브 요소에 접근 가능해야 한다
- 포커스 표시(focus ring)가 시각적으로 확인 가능해야 한다

### 스크린 리더

- 아이콘 전용 버튼은 `aria-label` 또는 `sr-only` 텍스트를 제공한다
- 장식용 이미지/아이콘은 `aria-hidden="true"`로 숨긴다
- 의미 있는 이미지는 `alt` 텍스트를 필수로 제공한다
- 에러, 로딩, 상태 변경은 `aria-live` 또는 `role="alert"`/`role="status"`로 안내한다

### 폼

- 모든 입력 필드는 `<label>`과 연결한다
- 에러 메시지는 `role="alert"`로 안내한다
- 필수 필드는 `required` 또는 `aria-required="true"`를 표시한다

### 색상과 대비

- WCAG AA 기준: 본문 텍스트 4.5:1, 큰 텍스트(18px+) 3:1 대비 비율
- 색상만으로 정보를 전달하지 않는다

### 언어

- `<html lang="ko">`를 유지한다
