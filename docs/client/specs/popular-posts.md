# F-06: 인기 글 (7일/30일)

**상태:** DONE
**최종 수정:** 2026-05-02

---

## 1. 개요

사이드바(F-39)의 "인기글" 탭에서 최근 7일/30일 기준 조회수 상위 글을 표시한다. 기존 `/popular` 독립 페이지는 삭제하고, 사이드바 전용으로 전환한다.

## 2. 배경 및 동기

현재 인기 글은 `/popular` 독립 페이지에서만 표시된다. F-39 사이드바 도입으로 헤더 네비게이션이 삭제되면 `/popular` 페이지로의 진입점이 사라진다. 인기 글은 사이드바의 "최근글/인기글" 탭에서 제공하는 것이 자연스럽다.

## 3. 목표

- 사이드바 인기글 탭에서 조회수 상위 5개 글을 표시한다
- 7일/30일 기간 전환을 지원한다
- `/popular` 페이지를 삭제한다
- 기존 서버 API(`GET /api/stats/popular`)를 그대로 활용한다

## 4. 비목표

- 인기 글 독립 페이지
- 기간 커스텀 선택 (7일/30일 외)
- 인기 글 순위 변동 표시

### 5.2 UI 구성

#### 기간 전환 토글

- 7일/30일 pill 스타일 토글 (현재 `/popular` 페이지의 토글과 동일 디자인)
- 기본값: 7일
- 클라이언트 상태로 전환 (URL 변경 없음, 사이드바 내부 state)

#### 글 목록 항목

| 요소 | 스타일 |
|---|---|
| 순위 번호 | `text-body-sm`, `text-text-3` |
| 제목 | `text-body-sm`, `text-text-1`, 1줄 말줄임 (`line-clamp-1`) |
| 조회수 | `text-body-xs`, `text-text-4` |

- 각 항목은 `/posts/{slug}` 링크
- hover 시 제목 색상 전환 (`text-primary-1`)

### 5.3 데이터 흐름

```
사이드바 레이아웃 (SSR)
  └─ 초기 데이터: fetchPopularPosts(7) → 7일 인기글 5개

인기글 탭 (Client Component)
  └─ 7일/30일 토글 클릭
  └─ clientFetch → GET /api/stats/popular?days=30&limit=5
  └─ 리스트 갱신
```

- 초기 로드: SSR로 7일 데이터 프리페치
- 기간 전환: 클라이언트에서 API 호출하여 갱신

## 6. API 연동

| 메서드 | 경로 | 용도 | 변경 사항 |
|---|---|---|---|
| GET | `/api/stats/popular?days={n}&limit=5` | 인기글 조회 | 없음 (기존 API) |

서버 변경 없음. 기존 `GET /api/stats/popular` 엔드포인트를 `limit=5`로 호출.

### 응답 데이터

```typescript
interface PopularPost {
  postId: number;
  slug: string;
  title: string;
  pageviews: number;
  uniques: number;
}
```

사이드바에서는 `pageviews`만 표시. `uniques`는 사용하지 않으나 API 응답에 포함.
