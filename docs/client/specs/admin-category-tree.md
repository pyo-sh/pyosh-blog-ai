# F-24: 카테고리 트리 표시

**상태:** DRAFT
**최종 수정:** 2026-03-23

---

## 1. 개요

관리자 카테고리 관리 페이지의 카테고리 트리 표시. 재귀 렌더링, 접기/펼치기 토글, 배치 편집 모드(드래그 앤 드롭으로 순서 변경 + 부모 변경), 숨김 카테고리 필터, 일괄 선택 모드(공개/숨김 토글), 카테고리별 글 개수 표시를 제공한다.

## 2. 배경 및 동기

현재 구현 상태:

- 재귀 컴포넌트 (`TreeRow`) 기반 트리 렌더링
- 항상 전체 펼침 (접기/펼치기 없음)
- depth 영문 텍스트 표시 ("Root", "Depth 1")
- `isVisible: false` 숨김 뱃지만 표시
- 글 개수 미표시 (하위 카테고리 개수만)
- 드래그 앤 드롭 없음 (정렬 API `PATCH /categories/order`는 존재)
- 순서/부모 변경 시 개별 API 호출

개선이 필요한 부분:

- 카테고리가 많아지면 항상 펼쳐진 트리가 길어짐
- 계층 표현이 영문 텍스트에 의존
- 순서/부모 변경을 위한 드래그 앤 드롭 UI 없음
- 숨김 카테고리 관리가 불편 (일괄 처리 불가)
- 글 개수를 알려면 별도 페이지에서 확인해야 함

## 3. 목표

- 접기/펼치기 토글 + 전체 펼침/접힘 버튼을 제공한다
- 인덴트만으로 계층을 표현한다 (depth 텍스트 제거)
- 배치 편집 모드에서 `@dnd-kit/core`로 순서 변경 + 부모 변경(reparenting)을 지원한다
- 변경사항을 단일 배치 API로 트랜잭션 처리한다
- 숨김 카테고리 필터 (on/off)를 제공한다
- 일괄 선택 모드에서 공개/숨김을 일괄 토글한다
- 카테고리별 글 개수 (발행/전체)를 표시한다
- 하위 카테고리가 없는 리프 노드는 토글 화살표를 숨긴다

## 4. 비목표

- 카테고리 CRUD (생성/수정/삭제 모달은 F-25)
- 인라인 이름 편집
- 가상 스크롤 (카테고리 수가 수백 개 미만이므로 불필요)
- 트리 검색/필터링 (이름 검색)

## 5. 상세 설계

### 5.1 트리 렌더링

#### 기본 레이아웃

```
┌─ 카테고리 (12개) ────────────────────────────────────────────┐
│ [전체 펼침] [전체 접힘]  [숨김 표시 ○]  [일괄 선택] [배치 편집] │
├──────────────────────────────────────────────────────────────┤
│ ▼ 개발                                   발행 8 / 전체 12    │
│     ▶ Frontend                           발행 3 / 전체 4     │
│     ▼ Backend                            발행 3 / 전체 5     │
│         Node.js                          발행 2 / 전체 3     │
│         Database                         발행 1 / 전체 2     │
│     DevOps                               발행 2 / 전체 3     │
│ 일상                                     발행 5 / 전체 8     │
└──────────────────────────────────────────────────────────────┘
```

#### 계층 표현

- 인덴트만으로 계층 표현 (depth 텍스트, 연결선 없음)
- depth 당 `pl-6` (24px) 들여쓰기
- 하위 카테고리가 있는 노드: ▶ (접힘) / ▼ (펼침) 토글 아이콘
- 리프 노드 (하위 없음): 토글 아이콘 숨김, 아이콘 자리만큼 빈 공간 유지 (정렬)

#### 행 구성

```
[▼/▶/빈] [카테고리명] [slug 뱃지]              [발행 N / 전체 N]
```

- slug 뱃지: 텍스트 색상 `text-text-4`, 배경 `bg-background-3`
- 글 개수: 우측 정렬, `text-text-3`

### 5.2 접기/펼치기

#### 토글 동작

- 토글 아이콘(▶/▼) 클릭: 해당 노드의 자식만 접기/펼치기
- 기본 상태: **전체 접힘** (루트 카테고리만 표시)
- 토글 상태는 컴포넌트 내부 state로 관리 (페이지 이동 시 초기화)

#### 전체 펼침/접힘 버튼

```
[전체 펼침] [전체 접힘]
```

- 전체 펼침: 모든 노드 펼침
- 전체 접힘: 루트만 표시

### 5.3 숨김 카테고리 필터

#### 토글 스위치

```
[숨김 표시 ○]  →  클릭  →  [숨김 표시 ●]
```

- OFF (기본): `isVisible: true`인 카테고리만 표시
- ON: 모든 카테고리 표시, 숨김 카테고리는 `opacity-50` 처리

#### 숨김 카테고리 행

```
     DevOps (숨김)                         발행 0 / 전체 1
```

- 전체 행 `opacity-50`
- 카테고리명 옆에 "(숨김)" 텍스트

### 5.4 일괄 선택 모드

#### 진입/이탈

```
일반 모드:  [...] [일괄 선택] [배치 편집]

선택 모드:  [전체 선택] [숨기기] [보이기]   N개 선택됨  [선택 해제] [완료]
```

[일괄 선택] 클릭 → 선택 모드 진입:
- 각 행 왼쪽에 체크박스 표시
- 상단 액션 바 변경: [숨기기] [보이기] [선택 해제] [완료]

#### 동작

1. 체크박스로 카테고리 선택 (복수 선택)
2. [전체 선택] 클릭 → 현재 표시된 모든 카테고리 선택 (이미 전체 선택 시 전체 해제)
3. 선택 카운터 실시간 갱신: "N개 선택됨"
4. [숨기기] 클릭 → 선택된 카테고리의 `isVisible: false` 설정
5. [보이기] 클릭 → 선택된 카테고리의 `isVisible: true` 설정
6. 각 카테고리에 대해 `PATCH /categories/:id` 호출
7. 완료 후 목록 갱신 + 토스트 알림
8. [완료] 클릭 → 선택 모드 이탈

#### 제약

- 일괄 선택 모드와 배치 편집 모드는 동시에 활성화할 수 없음
- 선택 모드에서는 접기/펼치기 토글은 동작 유지

### 5.5 배치 편집 모드

#### 진입/이탈

```
일반 모드:  [...] [일괄 선택] [배치 편집]

편집 모드:  [변경사항: 3건]              [취소] [저장]
```

[배치 편집] 클릭 → 편집 모드 진입:
- 각 행 왼쪽에 드래그 핸들 (⠿) 표시
- 상단 액션 바 변경: [변경사항: N건] [취소] [저장]

#### 드래그 앤 드롭

`@dnd-kit/core` + `@dnd-kit/sortable` 사용.

**순서 변경 (같은 부모 내):**
- 같은 depth의 형제 노드 사이로 드래그
- 드롭 위치에 시각적 인디케이터 (파란 가로선) 표시
- sortOrder 값 자동 재계산

**부모 변경 (reparenting):**
- 다른 카테고리 위에 드래그하여 자식으로 이동
- 드롭 대상 카테고리 하이라이트 (`bg-primary-2/20`)
- 순환참조 방지: 자기 자신 또는 자손 노드 위에 드롭 불가 (드롭 대상 비활성 표시)

#### 드래그 시각 피드백

| 상태 | 시각 피드백 |
|---|---|
| 드래그 중인 항목 | `opacity-50`, 원래 위치에 placeholder |
| 형제 사이 드롭 가능 | 파란 가로선 (2px, `bg-primary-1`) |
| 부모로 드롭 가능 | 대상 행 `bg-primary-2/20` 하이라이트 |
| 드롭 불가 (순환참조) | 대상 행 `opacity-30`, 커서 `not-allowed` |

#### 변경 추적

```typescript
interface TreeChange {
  id: number;
  parentId: number | null;  // 변경된 경우만
  sortOrder: number;        // 변경된 경우만
}

// 편집 모드 진입 시 원본 스냅샷 저장
const [originalTree, setOriginalTree] = useState<Category[]>([]);
const [pendingChanges, setPendingChanges] = useState<TreeChange[]>([]);
```

- 편집 모드 진입 시 현재 트리 상태를 스냅샷
- 드래그할 때마다 로컬 트리 상태 업데이트 + pendingChanges 기록
- 변경사항 카운터 실시간 갱신 (`[변경사항: N건]`)

#### 저장

[저장] 클릭 시:
1. `pendingChanges`에서 실제 변경된 항목만 필터 (원본 대비 diff)
2. 단일 배치 API 호출: `PATCH /api/categories/tree`
3. 성공 → 편집 모드 이탈 + 토스트 + 목록 갱신
4. 실패 → 에러 메시지, 편집 모드 유지

#### 취소

[취소] 클릭 시:
- 변경사항이 있으면 확인 대화상자: "변경사항을 취소하시겠습니까?"
- 확인 → 스냅샷에서 원본 트리 복원, 편집 모드 이탈
- 변경사항이 없으면 즉시 이탈

#### 제약

- 배치 편집 모드와 일괄 선택 모드는 동시에 활성화할 수 없음
- 편집 모드에서는 접기/펼치기 동작 유지 (드래그 대상을 찾기 위해 펼쳐야 할 수 있음)
- 편집 모드 진입 시 자동으로 전체 펼침 (드래그 대상을 볼 수 있도록)

### 5.6 글 개수 표시

#### 표시 형식

```
발행 3 / 전체 5
```

- `발행`: status가 published이고 deletedAt이 null인 글 수
- `전체`: deletedAt이 null인 모든 글 수 (draft + published + archived)
- 하위 카테고리의 글은 포함하지 않음 (해당 카테고리에 직접 속한 글만)

#### 스타일

- `text-text-3`, 우측 정렬
- 글이 0개인 카테고리: `발행 0 / 전체 0` 표시

## 6. API 연동

| 메서드 | 경로 | 용도 | 비고 |
|---|---|---|---|
| GET | `/api/categories?include_hidden=true` | 카테고리 트리 (글 개수 포함) | 응답에 postCount 추가 |
| PATCH | `/api/categories/tree` | 배치 트리 변경 (순서 + 부모) | **신규** |
| PATCH | `/api/categories/:id` | 개별 공개/숨김 변경 | 기존 (일괄 선택에서 사용) |

### 서버 변경 필요사항

| 항목 | 설명 |
|---|---|
| GET 응답 | 카테고리별 `publishedPostCount`, `totalPostCount` 필드 추가 (LEFT JOIN + COUNT) |
| 신규 엔드포인트 | `PATCH /api/categories/tree` - 배치 트리 변경 |

### 배치 트리 변경 API

#### 요청

```typescript
// PATCH /api/categories/tree
interface BatchTreeUpdateBody {
  changes: Array<{
    id: number;
    parentId?: number | null;  // 변경 시만 포함
    sortOrder?: number;        // 변경 시만 포함
  }>;
}
```

#### 처리 (단일 트랜잭션)

```typescript
async updateCategoryTree(changes: TreeChange[]) {
  return this.db.transaction(async (tx) => {
    // 1. 모든 변경 대상 카테고리 존재 여부 검증
    // 2. 변경 후 트리 구조를 메모리에서 구성
    // 3. 순환참조 검증 (전체 트리 대상)
    // 4. 검증 통과 → parentId, sortOrder 일괄 UPDATE
    // 5. 실패 → 자동 롤백
  });
}
```

#### 응답

```typescript
// 성공
{ success: true, updated: number }

// 실패
{ success: false, error: string, details?: { id: number, reason: string }[] }
```

#### 에러 케이스

| 에러 | HTTP | 응답 |
|---|---|---|
| 순환참조 감지 | 409 | `{ error: "circular_reference", details: [{ id, reason }] }` |
| 카테고리 미존재 | 404 | `{ error: "not_found", details: [{ id }] }` |
| 빈 changes 배열 | 400 | `{ error: "empty_changes" }` |

## 7. 수용 기준

- [ ] 카테고리 트리가 인덴트로 계층 표현된다 (depth 텍스트 없음)
- [ ] 기본 상태에서 전체 접힘 (루트만 표시)
- [ ] 토글 아이콘(▶/▼) 클릭으로 자식을 접기/펼치기할 수 있다
- [ ] 리프 노드에는 토글 아이콘이 표시되지 않는다
- [ ] [전체 펼침] / [전체 접힘] 버튼이 동작한다
- [ ] 숨김 필터 OFF 시 공개 카테고리만 표시된다
- [ ] 숨김 필터 ON 시 숨김 카테고리가 `opacity-50` + "(숨김)" 텍스트로 표시된다
- [ ] [일괄 선택] 클릭 시 체크박스가 나타난다
- [ ] [전체 선택] 버튼으로 모든 카테고리를 한번에 선택/해제할 수 있다
- [ ] 선택 카운터 ("N개 선택됨")가 실시간 갱신된다
- [ ] 선택 후 [숨기기]/[보이기] 버튼으로 일괄 변경된다
- [ ] [배치 편집] 클릭 시 드래그 핸들이 나타나고 전체 펼침된다
- [ ] 같은 부모 내에서 드래그로 순서를 변경할 수 있다
- [ ] 다른 카테고리 위에 드래그하여 부모를 변경할 수 있다
- [ ] 자기 자신 또는 자손 위에 드롭이 불가하다 (순환참조 방지)
- [ ] 드래그 시 시각 피드백 (placeholder, 하이라이트, 불가 표시)이 제공된다
- [ ] 변경사항 카운터가 실시간 갱신된다
- [ ] [저장] 시 단일 배치 API로 트랜잭션 처리된다
- [ ] [취소] 시 변경사항이 있으면 확인 대화상자가 표시된다
- [ ] [취소] 확인 시 원본 상태로 복원된다
- [ ] 카테고리별 글 개수가 "발행 N / 전체 N" 형태로 표시된다
- [ ] 일괄 선택 모드와 배치 편집 모드가 동시에 활성화되지 않는다
- [ ] 접근성: 키보드로 토글, 체크박스, 드래그 조작 가능 (A-01 참조)
- [ ] Storybook story 작성 (F-38 참조)
