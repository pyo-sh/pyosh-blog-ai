# F-09: 방명록

**상태:** DONE
**최종 수정:** 2026-05-02

---

## 1. 개요

방명록 페이지. 게스트 또는 OAuth 사용자가 방명록을 남기고, 비밀번호 또는 로그인 인증으로 삭제할 수 있다. 대댓글 없이 flat 구조로 운영한다.

## 2. 배경 및 동기

블로그 방문자가 간단한 메시지를 남길 수 있는 공간. 댓글(F-07, F-08)과 달리 특정 글에 종속되지 않는 독립적인 소통 채널이다.

## 3. 목표

- 게스트/OAuth 사용자가 방명록을 작성할 수 있다
- 비밀글 기능으로 관리자만 볼 수 있는 메시지를 남길 수 있다
- 작성자 본인이 삭제할 수 있다 (게스트: 비밀번호, OAuth: 로그인 인증)
- 관리자가 강제 삭제할 수 있다

## 4. 비목표

- 대댓글 (방명록은 flat 구조, 대댓글은 댓글 기능 F-08에서만 제공)
- 방명록 수정 (삭제만 가능)
- 새 방명록 알림 (이메일 등)
- 게스트 정보 localStorage 저장

---

## 5. 상세 설계

### 5.1 사용자 흐름

**방명록 작성 (게스트):**

1. `/guestbook` 접속
2. 이름, 이메일, 비밀번호, 본문 입력
3. 비밀글 체크 (선택)
4. 작성 버튼 클릭
5. 방명록 목록에 새 항목 추가, 해당 항목으로 스크롤 이동

**방명록 작성 (OAuth):**

1. `/guestbook` 접속 (로그인 상태)
2. 본문 입력 (이름/이메일/비밀번호 필드 미표시)
3. 비밀글 체크 (선택)
4. 작성 버튼 클릭

**방명록 삭제 (게스트):**

1. 본인 항목의 삭제 버튼 클릭
2. 비밀번호 입력 모달 표시
3. 비밀번호 입력 → 삭제 완료

**방명록 삭제 (OAuth):**

1. 본인 항목의 삭제 버튼 클릭
2. 삭제 확인 모달 (비밀번호 불필요)
3. 삭제 완료

### 5.2 UI 구성

#### 레이아웃

```
방명록                             총 42개 방명록

[작성 폼]
  게스트: 이름 | 이메일 | 비밀번호 (3열 그리드)
  본문 textarea
  [ ] 비밀글    [작성]

──────────────────────────
방명록 항목 1            3분 전
방명록 항목 2            1시간 전
방명록 항목 3            2일 전
...

[<<] [<]  1 2 3  [>] [>>]
```

#### 방명록 항목 표시

| 항목 | 설명 |
|---|---|
| 작성자명 | 게스트: 입력한 이름, OAuth: 계정 이름 |
| 본문 | 방명록 내용 |
| 작성 시간 | 상대 시간 표시 ("3분 전", "1시간 전", "2일 전") |
| 비밀글 배지 | 비밀글인 경우 표시 |
| 삭제 버튼 | 본인 항목에만 표시 |

#### 비밀글

- 작성자와 관리자만 본문 확인 가능
- 비작성자에게는 "비밀 방명록입니다." 메시지 표시

#### 삭제된 항목

- 본문: "삭제된 방명록입니다." (status 기반 마스킹, body 데이터는 DB에 보존)
- soft delete (DB에서 status = "deleted", body 보존 - Admin이 원문 확인 및 복원 가능)

#### 빈 상태

- 방명록이 0개: EmptyState 컴포넌트 (F-13)

### 5.3 CommentForm 재사용

CommentForm 컴포넌트를 `variant="guestbook"`으로 재사용한다. 단, 방명록에서는 대댓글 기능을 비활성화한다:

- `parentId` prop 미전달
- 답글 버튼 미표시
- 대댓글 UI 미렌더링

현재 코드베이스에 `parentId` 필드와 `replies` 배열이 방명록 모델에 존재하나, v1에서 방명록은 flat 구조로 운영한다. 서버 API에서 `parentId`를 허용하지 않도록 제한하고, 응답에서 계층 구조 빌드를 생략한다.

### 5.4 데이터 흐름

```
/guestbook 페이지:
  Server Component SSR
    └─ fetchMeServer() → 사용자 타입 확인 (guest/oauth)
    └─ fetchGuestbook(page) → 방명록 목록 (flat, 최신순)

작성:
  CommentForm (variant="guestbook")
    └─ POST /api/guestbook → 201 → 목록 갱신 + 새 항목으로 스크롤

삭제:
  삭제 모달
    └─ DELETE /api/guestbook/:id → 204 → 로컬 상태 업데이트 (soft delete)
```

### 5.5 컴포넌트 구조 (FSD)

| 계층 | 컴포넌트 | 역할 |
|---|---|---|
| `app` | `guestbook/page.tsx` | SSR 페이지 (사용자 정보 + 목록 초기 데이터) |
| `features` | `GuestbookPageContent` | 목록 표시 + 삭제 모달 |
| `features` | `CommentForm` | 작성 폼 (variant="guestbook", parentId 비활성화) |
| `entities` | `guestbook/api.ts` | API 호출 함수 |
| `entities` | `guestbook/model.ts` | 타입 정의 |
| `shared` | `Pagination` | 페이지네이션 |
| `shared` | `Modal` | 삭제 확인 모달 |

## 6. API 연동

### GET /api/guestbook

기존 엔드포인트 활용. 변경사항:

| 항목 | 현재 | 변경 |
|---|---|---|
| 응답 구조 | 계층형 (replies 포함) | flat 목록 (replies 제거) |
| 정렬 | 최신순 | 유지 |
| 인증 | optionalAuth | 유지 |

쿼리 파라미터: `page`, `limit` (기본 20)

### POST /api/guestbook

기존 엔드포인트 활용. 변경사항:

| 항목 | 현재 | 변경 |
|---|---|---|
| `parentId` | optional | 제거 (방명록은 flat) |
| Rate limit | 10/분 | 유지 |
| CSRF | 적용 | 유지 |

### DELETE /api/guestbook/:id

기존 엔드포인트 활용. 변경사항 없음.

- 게스트: `{ guestPassword: string }` body 필수
- OAuth: body 불필요

### Admin 엔드포인트

| 엔드포인트 | 설명 |
|---|---|
| GET /api/admin/guestbook | 관리자 목록 (필터: authorType, startDate, endDate) |
| DELETE /api/admin/guestbook/:id | 관리자 강제 삭제 (비밀번호 불필요) |

### 서버 변경 사항

| 항목 | 설명 |
|---|---|
| POST /api/guestbook | `parentId` 필드 제거 또는 무시 |
| GET /api/guestbook | 계층 구조 빌드 생략, flat 목록 반환 |

## 7. 수용 기준

- [ ] `/guestbook` 접속 시 방명록 목록이 최신순으로 표시된다
- [ ] 상단에 총 방명록 수가 표시된다 ("총 N개 방명록")
- [ ] 작성 시간이 상대 시간으로 표시된다 ("3분 전", "1시간 전")
- [ ] 게스트: 이름, 이메일, 비밀번호, 본문 입력 후 작성 가능
- [ ] OAuth: 본문만 입력하여 작성 가능 (프로필 필드 미표시)
- [ ] 비밀글 체크 시 작성자와 관리자만 본문 확인 가능
- [ ] 작성 후 새 항목으로 스크롤 이동
- [ ] 대댓글 없음 - flat 구조
- [ ] 게스트 삭제: 비밀번호 입력 모달 → 검증 → 삭제
- [ ] OAuth 삭제: 확인 모달 → 삭제 (본인 항목만)
- [ ] 삭제된 항목: "삭제된 방명록입니다." 표시
- [ ] 관리자 강제 삭제 (비밀번호 불필요)
- [ ] 작성 rate limit: 10/분
- [ ] 페이지네이션 동작
- [ ] 방명록 0개 시 빈 상태 표시 (F-13)
- [ ] 다크모드 자동 적용
- [ ] 접근성: 폼 키보드 탐색, 모달 포커스 트랩 (A-01 참조)
- [ ] Storybook story 작성 (F-38 참조)

| 케이스 | 처리 |
|---|---|
