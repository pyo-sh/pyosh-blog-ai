# F-04: 태그 목록

**상태:** DONE
**최종 수정:** 2026-05-02

---

## 1. 개요

전체 태그를 배지 클라우드 형태로 표시하고, 태그 클릭 시 해당 태그의 글 목록 페이지로 이동한다. 사이드바에서는 상위 20개 태그를 표시하고 전체보기 링크를 제공한다.

## 2. 배경 및 동기

태그는 카테고리와 다르게 글에 자유롭게 부여되는 분류 수단이다. 태그 목록 페이지에서 전체 태그를 한눈에 확인하고, 관심 태그의 글을 빠르게 탐색할 수 있어야 한다.

## 3. 목표

- 전체 태그를 postCount 내림차순으로 배지 클라우드 형태로 표시한다
- 태그 클릭 시 해당 태그의 글 목록 페이지로 이동한다
- 사이드바에서 상위 20개 태그를 표시하고 전체보기 링크를 제공한다

## 4. 비목표

- 태그 정렬 옵션 (postCount 내림차순 고정)
- 태그 검색/필터 입력
- PostListItem 태그 배지 링크 (텍스트만 표시, 클릭 불가)
- 태그 클라우드 가중치 (폰트 크기 차등)

---

## 5. 상세 설계

### 5.1 사용자 흐름

**태그 목록 페이지:**

1. `/tags` 접속
2. 전체 태그 수 표시 ("총 N개 태그")
3. 배지 클라우드로 태그 표시 (postCount 내림차순)
4. 태그 배지 클릭 → `/tags/{slug}` 이동

**태그별 글 목록 페이지:**

1. `/tags/{slug}` 접속
2. 해당 태그가 연결된 공개 글 목록 표시
3. 페이지네이션으로 탐색
4. 존재하지 않는 태그 slug → 404

**사이드바 (F-39):**

1. 사이드바 태그 섹션에 상위 20개 태그 표시
2. 태그 클릭 → `/tags/{slug}` 이동
3. 하단 "태그 전체보기" 링크 → `/tags` 이동

### 5.2 UI 구성

#### 태그 목록 페이지

```
태그                          총 42개 태그

[#JavaScript 128 posts] [#React 95 posts] [#TypeScript 87 posts]
[#Next.js 64 posts] [#CSS 51 posts] [#Node.js 43 posts]
...
```

- 상단: 페이지 제목 + 전체 태그 수
- 배지: `rounded-full`, `border border-border-3`, `bg-background-1`
- 배지 내용: `#{tag.name}` + `{postCount} posts`
- 레이아웃: `flex flex-wrap gap-3`
- 정렬: postCount 내림차순

#### 태그별 글 목록 페이지

- 상단: 태그명 (`#{tag.name}`)
- 글 목록: F-01과 동일한 리스트 아이템 형태
- 페이지네이션: F-01과 동일

#### PostListItem 태그 배지

- 글 카드 하단에 소형 배지로 표시
- 클릭 불가 (텍스트만)
- 스타일: `text-body-xs`, `rounded-full`, `border-border-3`

#### 사이드바 태그 섹션

- 상위 20개 태그만 배지로 표시
- 각 배지 클릭 시 `/tags/{slug}` 이동
- 하단: "태그 전체보기" 링크 → `/tags`

#### 빈 상태

- 태그가 0개: "등록된 태그가 없습니다." (EmptyState 컴포넌트, F-13)
- 사이드바: 태그 0개면 태그 섹션 미표시 (F-39에서 확정)

### 5.3 데이터 흐름

```
/tags 페이지:
  Server Component SSR
    └─ fetchTags() → GET /api/tags
    └─ postCount 내림차순 정렬 → 배지 클라우드 렌더링

/tags/[slug] 페이지:
  Server Component SSR
    └─ Promise.all([
         fetchTags(),
         fetchPosts({ tagSlug: slug, page })
       ])
    └─ 태그 미존재 → notFound()

사이드바:
  레이아웃 레벨 SSR
    └─ fetchTags() → 상위 20개 슬라이스 → 배지 렌더링
```

### 5.4 컴포넌트 구조 (FSD)

| 계층 | 컴포넌트 | 역할 |
|---|---|---|
| `app` | `tags/page.tsx` | 태그 목록 SSR 페이지 |
| `app` | `tags/[slug]/page.tsx` | 태그별 글 목록 SSR 페이지 |
| `entities` | `tag/api.ts` | `fetchTags()` |
| `entities` | `tag/model.ts` | `Tag` 타입 정의 |
| `features` | `TagCloud` | 사이드바용 태그 배지 (F-39) |

## 6. API 연동

### GET /api/tags

기존 엔드포인트 활용. 변경사항 없음.

| 항목 | 값 |
|---|---|
| 응답 | `{ tags: Tag[] }` |
| 정렬 | postCount 내림차순, 이름 오름차순 |
| 필터 | 공개(published) + 미삭제 글이 1개 이상인 태그만 |

### GET /api/posts (태그 필터)

기존 엔드포인트 활용. 변경사항 없음.

| 파라미터 | 설명 |
|---|---|
| `tagSlug` | 태그 slug로 필터링 |
| `page` | 페이지 번호 |

### 서버 변경 사항

없음. 기존 API로 충분.

## 8. 에지 케이스

| 케이스 | 처리 |
|---|---|
| 태그가 0개 | "등록된 태그가 없습니다." 빈 상태 표시 |
