# F-29: 방명록 관리 (목록, 강제 삭제)

**상태:** DRAFT
**최종 수정:** 2026-03-24

---

## 1. 개요

관리자 방명록 관리 페이지. 전체 방명록을 테이블로 표시하며, 상태/작성자/기간 필터, 작성자/내용 검색, 상세 모달, 소프트/영구 삭제 선택, 벌크 선택(페이지 간 유지) + 벌크 삭제/숨김, 방명록 기능 on/off 토글을 제공한다. Admin은 비밀 방명록을 마스킹 없이 확인할 수 있다.

## 2. 배경 및 동기

현재 구현 상태:

- 페이지네이션 테이블 (10개/페이지)
- 작성자, 내용, 비밀 여부, 날짜, 삭제 버튼
- 삭제 (soft delete만)
- 서버 필터 지원: authorType, startDate, endDate (UI 미구현)

개선이 필요한 부분:

- 필터/검색 UI 없음
- Hard delete 미구현
- 소프트/영구/숨김 선택 불가
- 상세 보기 없음
- 벌크 작업 없음
- 방명록 기능 on/off 없음

## 3. 목표

- 상태/작성자/기간 필터와 검색을 제공한다
- 상세 모달 (본문 전문 + 메타데이터)을 제공한다
- 소프트/영구 삭제와 숨김 처리를 선택할 수 있게 한다
- 벌크 선택(페이지 간 유지) + 벌크 삭제/숨김을 지원한다
- 방명록 기능 on/off 토글을 제공한다

## 4. 비목표

- 방명록 내용 수정 (Admin이 방명록을 편집하지 않음)
- 방명록 답글 (F-09 스펙에서 flat 구조로 확정)
- Admin 답글 작성
- 방명록 검색 고급 옵션 (정규식 등)

## 5. 상세 설계

### 5.1 방명록 on/off 토글

페이지 상단에 방명록 기능 활성화 토글을 배치한다.

```
┌─ 방명록 관리 ────────────────────────────────────────────┐
│                                                            │
│  방명록 기능  [🔘 활성]                                    │
│                                                            │
│  ──────────────────────────────────────────────────       │
│  (테이블 영역)                                             │
└────────────────────────────────────────────────────────────┘
```

- ON: 공개 페이지에서 방명록 작성/표시 가능
- OFF: 공개 페이지에서 방명록 영역 숨김 + 작성 API 차단
- Admin 관리 페이지에서는 OFF 상태에서도 기존 방명록 조회/관리 가능
- 토글 변경 시 즉시 반영 (확인 모달 없음)

#### 서버 구현

```typescript
// site_settings 테이블 (key-value)
{ key: "guestbook_enabled", value: "true" | "false" }
```

- `GET /api/settings/guestbook` - 현재 상태 조회 (Public)
- `PATCH /api/admin/settings/guestbook` - 상태 변경 (Admin)
- 공개 방명록 API (`POST /api/guestbook`)에서 설정 확인 → OFF면 403

### 5.2 테이블 구성

```
┌─ 방명록 관리 ────────────────────────────────────────────────────┐
│ 방명록 기능  [🔘 활성]                                            │
│                                                                    │
│ 상태: [전체 ▼]  작성자: [전체 ▼]  [기간 설정]  [검색어___] [🔍]   │
│                                                                    │
│ ☐ │ 작성자          │ 내용              │ 🔒 │ 상태  │ 날짜       │
│ ☑ │ 홍길동 [게스트]  │ 안녕하세요! 블... │    │ 정상  │ 2026.03.20 │
│ ☑ │ 김철수 [OAuth]  │ 블로그 잘 보고... │ 🔒 │ 정상  │ 2026.03.21 │
│ ☐ │ 이영희 [게스트]  │ 좋은 블로그네...  │    │ 삭제됨│ 2026.03.19 │
│                                                                    │
│ 총 28개 중 1-10                          [이전] 1/3 [다음]        │
└────────────────────────────────────────────────────────────────────┘
```

#### 컬럼 상세

| 컬럼 | 내용 | 비고 |
|---|---|---|
| ☐ | 벌크 선택 체크박스 | 헤더에 전체 선택/해제 |
| 작성자 | 이름 + 타입 뱃지 [게스트]/[OAuth] | |
| 내용 | 본문 1줄 truncate | **클릭 → 상세 모달** |
| 🔒 | 비밀 방명록 아이콘 | 비밀 아닌 경우 빈 칸 |
| 상태 | 뱃지: 정상/삭제됨/숨김 | |
| 날짜 | 작성일 (ko-KR) | |

- Admin이므로 비밀 방명록 본문도 마스킹 없이 표시
- 방명록은 flat 구조이므로 답글/글 제목 컬럼 없음

### 5.3 필터 + 검색

```
상태: [전체 ▼]  작성자: [전체 ▼]  [기간 설정]  [검색어 입력___] [🔍]
```

| 필터 | 옵션 | 서버 파라미터 |
|---|---|---|
| 상태 | 전체 / 정상 / 삭제됨 / 숨김 | `status` (신규) |
| 작성자 타입 | 전체 / OAuth / 게스트 | `authorType` (기존) |
| 기간 | 시작일 ~ 종료일 date picker | `startDate`, `endDate` (기존) |
| 검색 | 작성자 이름 + 본문 텍스트 검색 | `q` (신규) |

- 검색: Enter 또는 🔍 클릭 시 실행
- 검색 중 "'{검색어}' 검색 결과 (N건)" 표시 + X 버튼으로 해제
- 서버: `WHERE (guest_name LIKE '%q%' OR body LIKE '%q%')`, OAuth 사용자는 JOIN으로 이름 검색 포함

### 5.5 삭제/숨김 (단일)

상세 모달 또는 테이블에서 삭제 시 방식 선택:

```
┌─ 방명록 처리 ────────────────────────────────┐
│                                                │
│  처리 방식을 선택하세요.                       │
│                                                │
│  ⚪ 숨기기                                     │
│     공개 페이지에서 숨겨집니다.                 │
│     관리 페이지에서 확인 가능합니다.            │
│                                                │
│  ⚪ 소프트 삭제                                │
│     "삭제된 방명록입니다"로 표시됩니다.         │
│                                                │
│  ⚪ 영구 삭제                                  │
│     완전히 삭제됩니다.                          │
│     이 작업은 되돌릴 수 없습니다.              │
│                                                │
│                        [취소]  [확인]          │
└────────────────────────────────────────────────┘
```

| 방식 | 동작 |
|---|---|
| 숨기기 | `status: "hidden"` - 공개 미노출, Admin에서 관리 가능 |
| 숨김 복원 | `status: "active"` - 숨김 상태에서 정상으로 복원 |
| 소프트 삭제 | `status: "deleted"`, `body: ""`, `deletedAt: now()` |
| 영구 삭제 | DB에서 완전 삭제 (flat이므로 cascade 없음) |

상세 모달에서 현재 상태에 따라 버튼이 달라진다:

| 현재 상태 | 표시 버튼 |
|---|---|
| 정상 | [숨기기] [소프트 삭제] [영구 삭제] |
| 숨김 | [복원] [소프트 삭제] [영구 삭제] |
| 삭제됨 | [영구 삭제] |

### 5.6 벌크 선택 + 벌크 작업

#### 선택

체크박스 상시 표시. **페이지/필터 변경 시 선택 유지** (ID 기반).

```
┌──────────────────────────────────────────────────────────────────┐
│ ☑ 전체  선택됨 5개 (다른 페이지 2개 포함)  [전체 해제]           │
│                                                                   │
│                    [숨기기] [소프트 삭제] [영구 삭제]             │
├──────────────────────────────────────────────────────────────────┤
```

| 요소 | 동작 |
|---|---|
| ☑ 전체 | 현재 페이지 전체 선택/해제 토글 |
| 선택됨 N개 | 카운터 (다른 페이지 포함 시 표시) |
| [전체 해제] | 모든 페이지의 선택 초기화 |
| [숨기기] | 선택된 방명록 일괄 `status: hidden` |
| [복원] | 선택된 숨김 방명록 일괄 `status: active` |
| [소프트 삭제] | 선택된 방명록 일괄 soft delete |
| [영구 삭제] | 확인 모달 → 일괄 hard delete |

#### 벌크 API

```
DELETE /api/admin/guestbook/bulk
{
  ids: [1, 2, 3],
  action: "hide" | "restore" | "soft_delete" | "hard_delete"
}
```

- 단일 트랜잭션: 전체 성공 or 전체 실패
- 완료 후: selectedIds에서 처리된 ID 제거, 목록 갱신

## 6. API 연동

| 메서드 | 경로 | 용도 | 비고 |
|---|---|---|---|
| GET | `/api/admin/guestbook` | 방명록 목록 | `status`, `q` 파라미터 추가 |
| DELETE | `/api/admin/guestbook/:id` | 단일 삭제 | `?action=hide\|soft\|hard` |
| DELETE | `/api/admin/guestbook/bulk` | 벌크 삭제/숨김 | **신규** |
| GET | `/api/settings/guestbook` | 방명록 활성 상태 조회 | **신규** (Public) |
| PATCH | `/api/admin/settings/guestbook` | 방명록 활성 상태 변경 | **신규** (Admin) |

### 서버 변경 필요사항

| 항목 | 설명 |
|---|---|
| `status` 필터 | `AdminGuestbookQuerySchema`에 `status` 파라미터 추가 |
| `q` 검색 | `AdminGuestbookQuerySchema`에 `q` 파라미터 추가, guest_name + body LIKE 검색 |
| 단일 삭제 확장 | `action` 쿼리 파라미터로 hide/soft/hard 구분 |
| Hard delete 구현 | DB에서 완전 삭제 (flat이므로 cascade 없음) |
| 벌크 삭제 엔드포인트 | `DELETE /api/admin/guestbook/bulk` 신규 |
| 설정 API | `site_settings` 테이블 + 조회/변경 엔드포인트 |
| 공개 API 차단 | `POST /api/guestbook`에서 guestbook_enabled 확인 |

## 7. 수용 기준

- [ ] 방명록 on/off 토글이 페이지 상단에 표시된다
- [ ] 토글 OFF 시 공개 페이지에서 방명록 영역이 숨겨진다
- [ ] 토글 OFF 시 방명록 작성 API가 403을 반환한다
- [ ] Admin 페이지에서는 OFF 상태에서도 기존 방명록을 관리할 수 있다
- [ ] 테이블에 작성자, 내용, 비밀, 상태, 날짜가 표시된다
- [ ] 비밀 방명록이 마스킹 없이 표시된다
- [ ] 상태 필터 (전체/정상/삭제됨/숨김)가 동작한다
- [ ] 작성자 타입 필터 (전체/OAuth/게스트)가 동작한다
- [ ] 기간 필터가 동작한다
- [ ] 검색으로 작성자 이름과 본문을 검색할 수 있다
- [ ] 내용 클릭 시 상세 모달이 열린다
- [ ] 상세 모달에 원문, 작성자, 이메일, 날짜, 비밀/상태가 표시된다
- [ ] 정상 상태에서 숨기기/소프트 삭제/영구 삭제가 가능하다
- [ ] 숨김 상태에서 복원/소프트 삭제/영구 삭제가 가능하다
- [ ] 벌크 복원으로 숨김 방명록을 일괄 정상으로 되돌릴 수 있다
- [ ] 체크박스로 벌크 선택이 가능하다
- [ ] 페이지/필터 변경 시 선택이 유지된다
- [ ] [전체 해제]로 모든 선택을 초기화할 수 있다
- [ ] 벌크 숨기기/소프트 삭제/영구 삭제가 서버 벌크 API로 처리된다
- [ ] 소프트 삭제된 방명록 항목은 [영구 삭제] 버튼만 표시된다
- [ ] 접근성: 모달 focus trap, 필터 키보드 조작 (A-01 참조)

## 8. 에지 케이스

| 케이스 | 처리 |
|---|---|
| 방명록 OFF 상태에서 사용자가 API 직접 호출 | 서버 403 반환 |
| 벌크 삭제 중 일부 이미 삭제됨 | 서버에서 무시, 처리 건수만 반환 |
| 검색어에 SQL 특수문자 (%, _) | 서버에서 이스케이프 처리 |
| 방명록 on/off 토글 API 실패 | 토글 상태 원복 + 에러 토스트 |
| 날짜 필터 시작일 > 종료일 | 검색 결과 0건 반환 |
| 검색 결과 0건 | "검색 결과가 없습니다" 빈 상태 |
| 방명록 0건 | "방명록이 없습니다" 빈 상태 |
| 필터/검색 변경 후 선택된 항목이 목록에 안 보임 | 선택 유지 (ID 기반), 카운터에 반영 |
