React Server Components의 핵심 개념

RSC는 서버에서만 실행되는 React 컴포넌트입니다. 클라이언트 번들에 포함되지 않으므로 번들 크기를 줄일 수 있습니다.

서버 컴포넌트 vs 클라이언트 컴포넌트

서버 컴포넌트는 'use server' 지시어가 필요하지 않습니다. Next.js App Router에서는 기본적으로 모든 컴포넌트가 서버 컴포넌트입니다.

// 서버 컴포넌트 (기본) async function PostList() { const posts = await db.posts.findMany(); return <ul>{posts.map(p => <li key={p.id}>{p.title}</li>)}</ul>; }

서버 컴포넌트에서는 useState, useEffect 같은 클라이언트 훅을 사용할 수 없습니다.

주요 장점

  • 번들 크기 감소: 서버에서만 실행되는 코드는 클라이언트로 전송되지 않습니다
  • 직접 데이터 접근: API 레이어 없이 DB에 직접 접근 가능
  • 자동 코드 분할: 각 서버 컴포넌트가 자동으로 분할됩니다
