# [F-39] Public 사이드바 레이아웃

> Public 페이지에 2컬럼 레이아웃을 적용한다. 왼쪽 사이드바에 최근글/인기글, 카테고리 트리, 태그, 블로그 조회수를 배치하고, 오른쪽에 메인 콘텐츠를 표시한다.

## SPEC 참조

- `docs/client/specs/public-sidebar.md`

## 와이어프레임

- `docs/client/designs/public/home-page-sidebar.html` - 사이드바 포함 홈 페이지 레이아웃
- 공통 디자인 시스템: `docs/client/designs/DESIGN_SYSTEM.md`

## 상세 설계

### 사용자 흐름

**데스크톱 (>= 1080px):**

1. Public 페이지 접속
2. 왼쪽 사이드바 + 오른쪽 메인 콘텐츠 2컬럼 표시
3. 사이드바에서 카테고리 클릭 → 해당 카테고리 글 목록 이동
4. 최근글/인기글 탭 전환 → 리스트 갱신
5. 태그 클릭 → 해당 태그 글 목록 이동

**모바일 (< 1080px):**

1. Public 페이지 접속 - 메인 콘텐츠만 표시
2. 헤더 우측 햄버거 아이콘 클릭
3. 오른쪽에서 사이드바 슬라이드-인 + 배경 오버레이 딤 처리
4. 사이드바 내 항목 클릭 → 페이지 이동, 사이드바 자동 닫힘
5. 오버레이 클릭 또는 햄버거 재클릭 → 사이드바 닫힘
6. 브라우저 리사이즈로 1080px 이상이 되면 슬라이드-인 사이드바 자동 닫힘

### UI 구성

#### Header 변경

- 기존 수평 네비게이션(Home, Popular, Tags, Guestbook) 삭제
- 우측 아이콘 배치: 검색 | 다크모드 | 햄버거 (모바일만)
- 햄버거 아이콘은 1080px 미만에서만 표시

#### 사이드바 섹션 (위 → 아래)

| 순서 | 섹션 | 설명 |
|---|---|---|
| 1 | 최근글 / 인기글 탭 | 탭 전환으로 리스트 표시. 각 항목: 제목 + 날짜 |
| 2 | 분류 (카테고리) | 트리 구조. "분류 전체보기 (N)" 헤더 + 계층형 카테고리 + 글 수 |
| 3 | 태그 | 상위 20개 태그 배지 + "태그 전체보기" 링크 (→ `/tags`) |
| 4 | 블로그 조회수 | 총 조회수 카운터 |

#### 카테고리 트리

- 상위 카테고리 클릭 시 하위 카테고리 토글 (접기/펼치기)
- 기본 상태: 모두 접힌 상태
- 각 카테고리 옆에 글 수 표시

#### 사이드바 스크롤 동작

사이드바에 자체 스크롤바를 표시하지 않는다. 대신 JavaScript로 메인 콘텐츠 스크롤에 연동하여 사이드바 위치를 제어한다.

- `position: sticky`, `top: 70px` (nav 높이 + 여백) 기본 적용
- 사이드바 콘텐츠가 뷰포트보다 짧을 때: sticky로 상단 고정
- 사이드바 콘텐츠가 뷰포트보다 길 때: 페이지 스크롤 방향에 따라 사이드바 `top` 값을 JS로 조정하여 메인 콘텐츠와 함께 자연스럽게 스크롤
- `overflow-y` 사용 금지 - 사이드바 자체에 스크롤바가 보이지 않아야 한다

#### 모바일 슬라이드-인

- 오른쪽에서 슬라이드-인 애니메이션
- 배경 오버레이 딤 처리
- 뷰포트가 1080px 이상으로 변경되면 슬라이드-인 및 오버레이 자동 해제

#### 반응형 동작

| 조건 | 동작 |
|---|---|
| >= 1080px | 사이드바 왼쪽 고정 표시, 2컬럼 레이아웃 |
| < 1080px | 사이드바 숨김, 헤더에 햄버거 표시, 클릭 시 오른쪽 슬라이드-인 |

### 데이터 흐름

```
사이드바 데이터:
  최근글: GET /api/posts?limit=5 (기본 정렬 published_at desc)
  인기글: GET /api/stats/popular?days=7&limit=5 (F-06 엔드포인트 재사용)
  카테고리: GET /api/categories (트리 구조 + 글 수)
  태그: GET /api/tags
  조회수: GET /api/stats/total-views

페칭 전략:
  Server Component SSR → 사이드바 데이터 초기 로드
  레이아웃 레벨에서 페칭하여 페이지 전환 시 재요청 없음
```

### 컴포넌트 구조 (FSD)

| 계층 | 컴포넌트 | 역할 |
|---|---|---|
| `app` | `(public)/layout.tsx` | Public 라우트 그룹 레이아웃 (2컬럼) |
| `widgets` | `PublicSidebar` | 사이드바 전체 조합 |
| `widgets` | `Header` | 헤더 수정 (네비게이션 삭제, 아이콘 배치) |
| `features` | `RecentPopularPosts` | 최근글/인기글 탭 + 리스트 |
| `features` | `CategoryTree` | 카테고리 트리 (접기/펼치기) |
| `features` | `TagCloud` | 태그 목록 |
| `features` | `TotalViewCount` | 블로그 총 조회수 |
| `shared` | `SlideInPanel` | 모바일 슬라이드-인 + 오버레이 공통 컴포넌트 |

- `(public)` 라우트 그룹을 새로 생성하여 기존 Public 페이지를 이동
- Admin(`/manage`) 페이지는 영향 없음

## API 연동

### GET /api/posts (최근글)

기존 엔드포인트 활용. `limit=5`로 소량 조회.

- 기본 정렬(`published_at desc`)이 최신순이므로 추가 파라미터 불필요
- 응답 필드: `id`, `title`, `slug`, `publishedAt` (사이드바 리스트에 필요한 최소 필드)

### GET /api/stats/popular (인기글)

F-06에서 사용하는 기존 엔드포인트 재사용. `days=7&limit=5`로 조회.

- 7일/30일 기간 전환은 F-06 사이드바 탭에서 처리

### GET /api/categories

기존 엔드포인트 활용. 변경사항:

| 항목 | 현재 | 변경 |
|---|---|---|
| 응답 구조 | flat list | 트리 구조 (parent-child 관계 포함) |
| 응답 필드 | 없음 | 각 카테고리별 `publishedPostCount`, `totalPostCount` 추가 |

### GET /api/stats/total-views

신규 엔드포인트. `stats_daily_tb`에서 `postId IS NULL`인 행의 `SUM(pageviews)`를 반환.

```json
{ "totalPageviews": 12345 }
```

- 모든 페이지 방문이 `postId: NULL`로 기록됨 (F-10에서 처리)
- 글 조회수 합산이 아닌 **사이트 방문 수** 기준

### 서버 변경 필요사항

| 항목 | 설명 |
|---|---|
| 글 목록 API | `limit` 파라미터 지원 (기존 정렬 활용) |
| 카테고리 API | 트리 구조 응답 + `publishedPostCount`, `totalPostCount` 집계 |
| 통계 API | `GET /api/stats/total-views` 신규 (F-10 참조) |
| 통계 API | 전체 조회수 엔드포인트 신규 추가 |

## 수용 기준

- [ ] 모든 Public 페이지에 2컬럼 레이아웃이 적용된다
- [ ] 사이드바에 최근글/인기글 탭, 카테고리 트리, 태그, 조회수가 표시된다
- [ ] 최근글/인기글 탭 전환 시 리스트가 갱신된다
- [ ] 카테고리 트리: 기본 접힌 상태, 클릭 시 하위 카테고리 토글
- [ ] 카테고리/태그 클릭 시 해당 페이지로 이동한다
- [ ] 사이드바 콘텐츠가 짧으면 sticky, 길면 메인과 함께 스크롤
- [ ] Header 수평 네비게이션 삭제, 우측에 검색/다크모드/햄버거 아이콘 배치
- [ ] 1080px 미만: 사이드바 숨김, 햄버거 메뉴로 오른쪽 슬라이드-인
- [ ] 모바일 슬라이드-인 시 배경 오버레이 딤 처리
- [ ] 뷰포트 리사이즈로 1080px 이상 시 슬라이드-인 및 오버레이 자동 해제
- [ ] 레이아웃 레벨 SSR로 사이드바 데이터 로드, 페이지 전환 시 재요청 없음
- [ ] 다크모드 자동 적용
- [ ] 접근성: 사이드바 키보드 탐색, 카테고리 트리 aria-expanded, 슬라이드-인 포커스 트랩 (A-01 참조)
- [ ] Storybook story 작성 (F-38 참조)

## 에지 케이스

| 케이스 | 처리 |
|---|---|
| 카테고리가 0개 | 분류 섹션 미표시 |
| 태그가 0개 | 태그 섹션 미표시 |
| 글이 0개 | 최근글/인기글 리스트에 빈 상태 메시지 |
| 카테고리 depth가 깊을 때 | 들여쓰기로 depth 표현, 제한 없음 |
| 모바일 사이드바 열린 상태에서 브라우저 뒤로가기 | 사이드바 닫힘 (히스토리 조작 없음, 페이지 이동) |
| 슬라이드-인 열린 상태에서 리사이즈 | 1080px 이상 도달 시 자동 닫힘 |
