# [F-28] 댓글 관리 (목록, 비밀글 확인, 강제 삭제)

> 관리자 댓글 관리 페이지. 전체 댓글을 테이블로 표시하며, 상태/작성자/글/기간 필터, 상세 모달(원문 + 메타데이터), 소프트/영구 삭제 선택, 벌크 선택(페이지 간 유지) + 벌크 삭제를 제공한다. Admin은 비밀 댓글을 마스킹 없이 확인할 수 있다.

│ [ ] │ 작성자          │ 내용              │ 글 제목        │비밀│상태 │날짜│

#### 컬럼 상세

| 컬럼 | 내용 | 비고 |
|---|---|---|
| 체크박스 | 벌크 선택 체크박스 | 헤더에 전체 선택/해제 |
| 작성자 | 이름 + 타입 뱃지 [게스트]/[OAuth] | 답글: `↳` 프리픽스 + `@대상이름` |
| 내용 | 본문 1줄 truncate | **클릭 → 상세 모달** |
| 글 제목 | 해당 글의 제목 (링크) | 클릭 → 글 페이지 이동. flat 목록이므로 답글에도 표시 |
| 비밀 | 비밀 댓글 아이콘 | 비밀 아닌 경우 빈 칸 |
| 상태 | 뱃지: 정상/삭제됨/숨김 | 정상: 기본, 삭제됨: `text-text-4`, 숨김: `text-yellow-1` |
| 날짜 | 작성일 (ko-KR 짧은 형식) | |

- Admin이므로 비밀 댓글 본문도 **마스킹 없이** truncate 표시
- 서버 API가 flat pagination을 반환하므로 모든 댓글이 날짜순으로 나열됨
- 답글은 `↳` 프리픽스 + `@대상이름`으로 구분
- 부모와 답글이 다른 페이지에 있을 수 있지만, `@대상이름`으로 맥락 파악 가능
- 글 제목은 답글에도 동일하게 표시 (flat 목록이므로 부모와 떨어져 있을 수 있음)

### 필터

```

| 필터 | 옵션 | 서버 파라미터 |

```

펼침:  ▼ 부모 댓글 숨기기
       ┌──────────────────────────────────────────┐

- ▶/▼ 아이콘 클릭으로 토글
- 루트 댓글(depth=0)이면 이 섹션 미표시

#### 모달 내 네비게이션 흐름

```
테이블에서 댓글 클릭
  → 상세 뷰 (단일 댓글)
     ├─ ▶ 부모 댓글 보기 (접기/펼치기)
     ├─ [관련 댓글 모두 보기]
     │    → 스레드 뷰 (부모 + 모든 답글)
     │       ├─ 다른 댓글 클릭 → 해당 댓글의 상세 뷰로 전환
     │       └─ [← 상세로 돌아가기] → 이전 상세 뷰
     ├─ [소프트 삭제] / [영구 삭제]
     └─ [x] / Esc → 모달 닫기
```

#### 기타

- 비밀 댓글도 마스킹 없이 원문 표시
- 게스트 이메일 표시 (공개 페이지에서는 미노출)
- [글 보기 →]: Admin 미리보기 페이지 (`/manage/posts/[id]/preview`) 이동
- 답글 대상: 답글인 경우만 표시
- 삭제됨/숨김 상태의 댓글도 원문 확인 가능

### 삭제 (단일)

상세 모달 또는 테이블에서 삭제 시 방식 선택 모달:

```
┌─ 댓글 삭제 ──────────────────────────────────┐
│                                                │
│  삭제 방식을 선택하세요.                       │
│                                                │
│  ( ) 소프트 삭제                                │
│     댓글이 "삭제된 댓글입니다"로 표시됩니다.   │
│                                                │
│  ( ) 영구 삭제                                  │
│     댓글이 완전히 삭제됩니다.                   │
│     이 작업은 되돌릴 수 없습니다.              │
│     ! 대댓글 2개가 함께 삭제됩니다.            │
│                                                │
│                        [취소]  [삭제]          │
└────────────────────────────────────────────────┘
```

#### 소프트 삭제

- `status: "deleted"`, `deletedAt: now()` (body 보존)
- 공개 페이지에서 status 기반으로 "삭제된 댓글입니다" 플레이스홀더 표시 (body를 비우지 않음)
- Admin 페이지에서 원문 확인 가능, 상태 뱃지 "삭제됨"으로 변경
- Admin이 복원 또는 영구 삭제를 결정

#### 영구 삭제 (hard delete)

- DB에서 완전 삭제
- 대댓글 cascade: 해당 댓글의 모든 replies도 함께 삭제
- 단일 트랜잭션 처리

```typescript
async hardDeleteComment(id: number) {
  await db.transaction(async (tx) => {
    // 1. 대댓글 삭제 (parentId = id)
    await tx.delete(commentTable).where(eq(commentTable.parentId, id));
    // 2. 댓글 삭제
    await tx.delete(commentTable).where(eq(commentTable.id, id));
  });
}
```

### 벌크 선택 + 벌크 삭제

#### 선택 모드

테이블 체크박스로 선택. **페이지 이동해도 선택 유지.**

```
선택됨 15개 (다른 페이지 7개 포함)  [전체 선택] [전체 해제] [복원] [소프트 삭제] [영구 삭제]
```

#### 동작

| 트리거 | 동작 |
|---|---|
| 개별 체크박스 | 해당 댓글 선택/해제 토글 |
| 헤더 체크박스 | 현재 페이지 전체 선택/해제 |
| [전체 선택] | 현재 페이지 전체를 기존 선택에 추가 |
| [전체 해제] | 모든 페이지의 선택 초기화 |
| 페이지 이동 | 선택 유지, 카운터에 "(다른 페이지 N개 포함)" 표시 |

#### 벌크 삭제 모달

```
┌─ 일괄 삭제 ──────────────────────────────────┐
│                                                │
│  15개 댓글을 삭제합니다.                       │
│                                                │
│  ( ) 소프트 삭제                                │
│  ( ) 영구 삭제                                  │
│     ! 관련 대댓글도 함께 삭제됩니다.            │
│                                                │
│                        [취소]  [삭제]          │
└────────────────────────────────────────────────┘
```

#### 벌크 API

```
DELETE /api/admin/comments/bulk
{
  ids: [1, 2, 3, ...],
  action: "restore" | "soft_delete" | "hard_delete"
}
```

- 단일 트랜잭션: 전체 성공 or 전체 실패
- restore: `status: "active"`, `deletedAt: null` 복원
- hard_delete: 각 댓글의 대댓글도 cascade 삭제
- 완료 후: selectedIds에서 처리된 ID 제거, 목록 갱신

## API 연동

| 메서드 | 경로 | 용도 | 비고 |
|---|---|---|---|
| GET | `/api/admin/comments` | 댓글 목록 (필터 + 페이지네이션) | 응답에 post.title 추가 |
| GET | `/api/admin/comments/:id/thread` | 스레드 조회 (부모 + 모든 답글) | **신규** |
| PUT | `/api/admin/comments/:id/restore` | 댓글 복원 (deleted → active) | **신규** |
| DELETE | `/api/admin/comments/:id` | 단일 삭제 | `?action=soft_delete` 또는 `?action=hard_delete` |
| DELETE | `/api/admin/comments/bulk` | 벌크 삭제/복원 | **신규** |

### 서버 변경 필요사항

| 항목 | 설명 |
|---|---|
| Admin 댓글 목록 응답 | `post: { id, title }` 필드 추가 (posts 테이블 JOIN) |
| `status` 필터 | `AdminCommentListQuerySchema`에 `status` 파라미터 추가 |
| 단일 삭제 확장 | `action` 쿼리 파라미터로 `soft_delete`/`hard_delete` 구분 |
| 단일 복원 엔드포인트 | `PUT /api/admin/comments/:id/restore` - deleted → active |
| Hard delete 구현 | cascade 대댓글 삭제 트랜잭션 |
| 스레드 조회 엔드포인트 | `GET /api/admin/comments/:id/thread` - 부모 + 답글 반환 |
| 벌크 엔드포인트 | `DELETE /api/admin/comments/bulk` 신규 |
| 벌크 스키마 | `{ ids: number[], action: "restore" | "soft_delete" | "hard_delete" }` |

## 수용 기준

- [ ] 댓글 테이블에 작성자, 내용, 글 제목, 비밀, 상태, 날짜가 표시된다
- [ ] 글 제목이 postId가 아닌 실제 제목으로 표시된다
- [ ] 글 제목 클릭 시 해당 글 페이지로 이동한다
- [ ] 답글은 `↳` 프리픽스로 표시되고 글 제목이 동일하게 표시된다
- [ ] 비밀 댓글이 마스킹 없이 표시된다
- [ ] 상태 필터 (전체/정상/삭제됨/숨김)가 동작한다
- [ ] 작성자 타입 필터 (전체/OAuth/게스트)가 동작한다
- [ ] 글 필터 (검색 가능 select)가 동작한다
- [ ] 기간 필터 (시작일~종료일)가 동작한다
