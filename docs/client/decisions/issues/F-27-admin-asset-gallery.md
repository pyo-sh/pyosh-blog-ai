## 상세 설계

### 그리드 레이아웃

#### 기본 모드

```
┌─ 에셋 갤러리 ──────────────────────────────────────────┐
│                                              [선택]     │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                  │
│ │  이미지   │ │  이미지   │ │  이미지   │                  │
│ │       [복사]│ │      [복사]│ │      [복사]│  <- URL 복사  │
│ ├──────────┤ ├──────────┤ ├──────────┤                  │
│ │ 2.5 MB   │ │ 512 KB   │ │ 1.2 MB   │                  │
│ │ 1920x1080│ │ 800x600  │ │ 640x480  │                  │
│ └──────────┘ └──────────┘ └──────────┘                  │
│                                                          │
│ 총 42개 중 1-18             [이전] 1/3 [다음]            │
└──────────────────────────────────────────────────────────┘
```

- 그리드: `sm:grid-cols-2 xl:grid-cols-3`
- 이미지: 4:3 비율, hover 시 `scale-[1.03]`
- 카드 하단: 파일 크기, 해상도 표시
- hover 시 우상단에 URL 복사 버튼 하나만 표시
- 클릭: 상세 모달 열기
- 길게 누르기 (500ms): 선택 모드 진입 + 해당 카드 선택

#### 선택 모드

```
┌─ 에셋 갤러리 ──────────────────────────────────────────┐
│ 선택됨 3개  [전체 선택]  [삭제]       [완료]  <- sticky  │
├──────────────────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                  │
│ │  이미지   │ │  이미지   │ │  이미지   │                  │
│ │ [v]      │ │ [v]      │ │ [ ]      │                  │
│ ├──────────┤ ├──────────┤ ├──────────┤                  │
│ │ 2.5 MB   │ │ 512 KB   │ │ 1.2 MB   │                  │
│ └──────────┘ └──────────┘ └──────────┘                  │
└──────────────────────────────────────────────────────────┘
```

- 선택 액션 바: `position: sticky; top: 64px` (Admin 헤더 높이 아래 고정)
- 스크롤해도 항상 보임

#### 모드 전환

| 트리거 | 동작 |
|---|---|
| 기본 모드 → [선택] 버튼 | 선택 모드 진입 |
| 기본 모드 → 카드 길게 누르기 (500ms) | 선택 모드 진입 + 해당 카드 선택 |
| 선택 모드 → [완료] 버튼 | 선택 모드 이탈, 선택 초기화 |
| 선택 모드 → Esc 키 | 선택 모드 이탈, 선택 초기화 |
| 선택 모드 → 카드 클릭 | 선택/해제 토글 (상세 모달 열리지 않음) |
| 선택 모드 → Shift+클릭 | 마지막 선택 카드부터 클릭 카드까지 연속 범위 선택 |

#### 길게 누르기 구현

```typescript
const HOLD_DURATION = 500; // ms

function useLongPress(callback: () => void) {
  const timerRef = useRef<NodeJS.Timeout>();

  const onPointerDown = () => {
    timerRef.current = setTimeout(callback, HOLD_DURATION);
  };

  const onPointerUp = () => {
    clearTimeout(timerRef.current);
  };

  return { onPointerDown, onPointerUp, onPointerLeave: onPointerUp };
}
```

- `pointerdown`/`pointerup` 이벤트로 마우스 + 터치 통합 처리
- hold 중 시각 피드백: 카드 테두리 또는 배경 서서히 변경 (디자인 위임)
- 500ms 전에 손을 떼면 일반 클릭 (상세 모달)

### 상세 모달

이미지 클릭 시 상세 모달을 표시한다.

```
┌─ 에셋 상세 ────────────────────────────────── [x] ─┐
│                                                      │
│  ┌──────────────────────────────────────────────┐   │
│  │                                               │   │
│  │          원본 이미지 미리보기                  │   │
│  │                                               │   │
│  └──────────────────────────────────────────────┘   │
│                                                      │
│  파일명:   f7a3b2c1-xxxx.jpg                        │
│  크기:     2.5 MB                                    │
│  해상도:   1920 x 1080                               │
│  형식:     image/jpeg                                │
│  업로드:   2026.03.23                                │
│  URL:      /uploads/2026/03/f7a3b2c1-xxxx.jpg       │
│                                                      │
│  [URL 복사]  [마크다운 복사]              [삭제]      │
└──────────────────────────────────────────────────────┘
```

#### 기능

| 버튼 | 동작 |
|---|---|
| [URL 복사] | URL 클립보드 복사 + "복사됨" 피드백 |
| [마크다운 복사] | `![파일명](url)` 클립보드 복사 + "복사됨" 피드백 |
| [삭제] | 삭제 확인 → 삭제 → 모달 닫기 + 갤러리 갱신 |
| [x] / Esc | 모달 닫기 |

#### 이전/다음 네비게이션

모달 내에서 좌우 화살표로 현재 페이지의 이전/다음 에셋으로 이동한다.

```
  [<-]  이미지 미리보기  [->]
```

- 좌우 화살표 키로도 이동 가능
- 첫 번째/마지막 에셋에서 해당 방향 화살표 비활성
- 메타데이터와 액션 버튼이 현재 에셋에 맞게 갱신

#### 이미지 미리보기

- 모달 내에서 원본 비율 유지, 최대 너비/높이 제한
- 이미지 클릭 시 새 탭에서 원본 열기 (`target="_blank"`)

### 벌크 삭제 API

`Promise.allSettled` 개별 호출을 서버 벌크 API로 변경한다.

```
DELETE /api/assets/bulk
{
  ids: [1, 2, 3]
}
```

#### 서버 처리 (단일 트랜잭션)

```typescript
async bulkDeleteAssets(ids: number[]) {
  await db.transaction(async (tx) => {
    for (const id of ids) {
      const asset = await getAssetById(tx, id);
      if (!asset) continue;  // 이미 삭제된 경우 무시

      // 물리 파일 삭제 (best-effort)
      await fileStorage.deleteFile(asset.storageKey).catch(logError);

      // DB 레코드 삭제
      await tx.delete(assetTable).where(eq(assetTable.id, id));
    }
  });
}
```

#### 응답

```typescript
// 성공
{ success: true, deletedCount: number }

// 실패
{ success: false, error: string }
```

### 갤러리 선택 모달 (F-23 연동)

F-23 썸네일 업로더의 [에셋 갤러리] 버튼에서 호출되는 모달.

```
┌─ 에셋 선택 ────────────────────────────────── [x] ─┐
│                                                      │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐              │
│ │  이미지   │ │  이미지   │ │  이미지   │              │
│ │          │ │  v 선택  │ │          │              │
│ └──────────┘ └──────────┘ └──────────┘              │
│                                                      │
│ [이전] 1/3 [다음]                                    │
│                                                      │
│                              [취소]  [선택]           │
└──────────────────────────────────────────────────────┘
```

#### 동작

1. 모달 열림: 에셋 갤러리 그리드 표시 (동일 API, 동일 페이지네이션)
2. 이미지 클릭: 단일 선택 (라디오 - 하나만 선택 가능)
3. 선택된 이미지에 체크 표시
4. [선택] 클릭: 선택된 에셋의 URL을 콜백으로 반환
5. [취소] / [x] / Esc: 모달 닫기

#### 인터페이스

```typescript
interface AssetPickerModalProps {
  isOpen: boolean;
  onSelect: (url: string) => void;  // 선택 시 URL 반환
  onClose: () => void;
}
```

- F-23 `ThumbnailUploader`에서 사용
- F-22 에디터 이미지 삽입에서도 재사용 가능

## API 연동

| 메서드 | 경로 | 용도 | 비고 |
|---|---|---|---|
| GET | `/api/assets` | 에셋 목록 (페이지네이션) | 기존 |
| GET | `/api/assets/:id` | 에셋 메타데이터 | 기존 |
| DELETE | `/api/assets/:id` | 개별 삭제 | 기존 (상세 모달에서 사용) |
| DELETE | `/api/assets/bulk` | 벌크 삭제 | **신규** |

### 서버 변경 필요사항

| 항목 | 설명 |
|---|---|
| 신규 엔드포인트 | `DELETE /api/assets/bulk` - 배열 ID 받아 트랜잭션 삭제 |
| 벌크 삭제 스키마 | `{ ids: number[] }` Zod 검증 |

## 수용 기준

- [ ] 이미지 클릭 시 상세 모달이 열린다
- [ ] 상세 모달에 원본 미리보기, 파일명, 크기, 해상도, 형식, 업로드일, URL이 표시된다
- [ ] 상세 모달에서 URL 복사, 마크다운 복사가 동작한다
- [ ] 상세 모달에서 삭제가 동작한다
- [ ] hover 시 우상단에 URL 복사 버튼만 표시된다
- [ ] [선택] 버튼으로 선택 모드에 진입한다
- [ ] 카드 길게 누르기 (500ms)로 선택 모드에 진입하고 해당 카드가 선택된다
- [ ] 선택 모드에서 카드 클릭으로 선택/해제가 토글된다
- [ ] 선택 모드에서 [전체 선택]으로 현재 페이지 전체 선택/해제가 가능하다
- [ ] 선택 모드에서 [삭제] 클릭 시 벌크 삭제 API가 호출된다
- [ ] Shift+클릭으로 연속 범위 선택이 가능하다
- [ ] 선택 액션 바가 sticky로 스크롤 시에도 보인다
- [ ] 상세 모달에서 좌우 화살표로 이전/다음 에셋을 탐색할 수 있다
- [ ] [완료] 또는 Esc로 선택 모드가 이탈된다
- [ ] 벌크 삭제가 서버 트랜잭션으로 처리된다
- [ ] 갤러리 선택 모달에서 이미지를 단일 선택할 수 있다
- [ ] 갤러리 선택 모달에서 [선택] 클릭 시 URL이 콜백으로 반환된다
- [ ] 페이지네이션이 18개 단위로 동작한다
- [ ] 에셋이 없을 때 빈 상태 메시지가 표시된다
- [ ] 접근성: 모달 focus trap, Esc 닫기, 키보드 네비게이션 (A-01 참조)
- [ ] Storybook story 작성 (F-38 참조)

## 에지 케이스

| 케이스 | 처리 |
|---|---|
| 상세 모달에서 삭제 후 | 모달 닫기 + 갤러리 갱신 |
| 벌크 삭제 중 일부 이미 삭제됨 | 서버에서 무시 (에러 아님), 성공 카운트만 반환 |
| 길게 누르기 중 포인터 이탈 | hold 취소, 일반 상태 유지 |
| 선택 모드에서 페이지 이동 | 선택 초기화 (다른 페이지 에셋은 선택 불가) |
| 갤러리 선택 모달에서 에셋 0개 | "에셋이 없습니다. 먼저 업로드해 주세요" 안내 |
| 이미지 로드 실패 | 플레이스홀더 이미지 표시 |
| 해상도 정보 없음 (width/height null) | "해상도 정보 없음" 텍스트 표시 |
| 모바일에서 hover | hover 액션(URL 복사) 미표시, 클릭으로 상세 모달 이용 |
| 상세 모달에서 첫 번째 에셋일 때 <- | 왼쪽 화살표 비활성 |
| 상세 모달에서 마지막 에셋일 때 -> | 오른쪽 화살표 비활성 |
| Shift+클릭 시 마지막 선택이 없음 | 일반 클릭과 동일 (단일 선택) |
| 상세 모달에서 삭제 후 다음 에셋 있음 | 다음 에셋으로 자동 이동 |
| 상세 모달에서 삭제 후 다음 에셋 없음 | 모달 닫기 |
