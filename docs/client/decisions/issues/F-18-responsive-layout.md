# [F-18] 반응형 레이아웃

> 모바일(320px)부터 데스크톱까지 대응하는 반응형 레이아웃 시스템. Tailwind 모바일 퍼스트 방식으로 3개 브레이크포인트를 사용한다.

## SPEC 참조

- `docs/client/specs/responsive-layout.md`

## 와이어프레임

- `docs/client/designs/public/home-page.html` - Public 레이아웃 (네비게이션, 컨테이너, footer)
- `docs/client/designs/admin/_admin-shell.html` - Admin 레이아웃 (사이드바, 헤더)
- 공통 디자인 시스템: `docs/client/designs/DESIGN_SYSTEM.md`

## 상세 설계

### 브레이크포인트

| 이름 | 최소 폭 | 대상 |
|---|---|---|
| (기본) | 0px | 모바일 |
| `sm` | 480px | 큰 모바일 |
| `md` | 768px | 태블릿 |
| `lg` | 1080px | 데스크톱 |

Tailwind 기본값에서 변경: `sm: 640→480`, `md: 768 유지`, `lg: 1024→1080`. `xl`, `2xl`은 사용하지 않는다. Header, Public 콘텐츠, 사이드바 브레이크포인트를 `67.5rem`(1080px)으로 통일한다.

### 레이아웃 구조

#### Public 영역

```
모바일 (< 768px)              데스크톱 (≥ 768px)
┌──────────────┐              ┌──────────────────────┐
│   Header     │              │      Header          │
│  (세로 스택)  │              │   (가로, 한 줄)       │
├──────────────┤              ├──────────────────────┤
│              │              │                      │
│   Content    │              │   Content            │
│  (단일 열)   │              │   (67.5rem 중앙)      │
│              │              │                      │
├──────────────┤              ├──────────────────────┤
│   Footer     │              │      Footer          │
└──────────────┘              └──────────────────────┘
```

- 콘텐츠 최대 폭: `max-w-[67.5rem]` (1080px)
- 좌우 패딩: 모바일 `px-4`, md 이상 `px-6`

#### Admin 영역

```
모바일 (< 768px)              데스크톱 (≥ 768px)
┌──────────────┐              ┌─────┬────────────────┐
│ [☰] Header   │              │ Side│                │
├──────────────┤              │ bar │   Content      │
│              │              │ w-60│                │
│   Content    │              │     │                │
│  (전체 폭)   │              │     │                │
│              │              │     │                │
└──────────────┘              └─────┴────────────────┘

햄버거 메뉴 열림:
┌──────────────┐
│ [✕] Header   │
├──────────────┤
│  Sidebar     │
│  (오버레이)   │
│  전체 폭      │
├──────────────┤
│  (배경 딤)    │
└──────────────┘
```

- 데스크톱: 사이드바 `w-60` 고정 + 콘텐츠 `flex-1`
- 모바일: 사이드바 숨김, 햄버거 버튼으로 오버레이 표시
- 오버레이 배경 딤 처리, 외부 클릭 시 닫힘

### 반응형 패턴

#### 헤더

| 속성 | 모바일 | md 이상 |
|---|---|---|
| 방향 | `flex-col` (세로 스택) | `flex-row` (가로 배치) |
| 높이 | `min-h-28` (7rem) | `h-[5.625rem]` |
| 네비게이션 | 전체 폭 | `w-auto` |

#### 글 리스트 아이템

| 속성 | 모바일 | md 이상 |
|---|---|---|
| 썸네일 | 숨김 (`hidden`) | 표시 (`md:block`) |
| 패딩 | `p-5` | `md:p-6` |

#### 그리드 레이아웃

| 영역 | 모바일 | sm | md | lg |
|---|---|---|---|---|
| 에셋 갤러리 | 1열 | 2열 | 2열 | 3열 |
| 대시보드 통계 | 2열 | 2열 | 3열 | 5열 |
| 글 에디터 폼 | 1열 | 1열 | 2열 | 3열 |

#### 페이지네이션 반응형

| 뷰포트 | 표시 범위 | 예시 |
|---|---|---|
| 모바일 (< 768px) | 현재 +-1 | `[<<] [<] 4 **5** 6 [>] [>>]` |
| md 이상 | 현재 +-3 | `[<<] [<] 1 2 3 ... 18 19 20 [>] [>>]` |

#### 검색바

| 속성 | 모바일 | md 이상 |
|---|---|---|
| 열림 폭 | `w-40` (10rem) | `md:w-56` (14rem) |

### 콘텐츠 오버플로우 처리

#### 이미지

본문 내 이미지가 뷰포트를 초과하지 않도록 강제한다.

```css
.prose img {
  max-width: 100%;
  height: auto;
}
```

#### 테이블

마크다운 테이블이 뷰포트보다 넓을 경우 가로 스크롤을 제공한다.

```css
.prose table {
  display: block;
  overflow-x: auto;
}
```

#### 코드 블록

기존 가로 스크롤 유지. 폰트 축소하지 않는다.

### 반응형 타이포그래피

body 텍스트는 고정, heading만 모바일에서 축소한다.

| 토큰 | 데스크톱 (>= 768px) | 모바일 (< 768px) |
|---|---|---|
| heading-xl | 32px | 24px |
| heading-lg | 24px | 20px |
| heading-md 이하 | 변경 없음 | 변경 없음 |
| body 계열 | 변경 없음 | 변경 없음 |

### 컴포넌트 구조 (FSD)

| 계층 | 컴포넌트 | 역할 |
|---|---|---|
| `app` | `layout.tsx` | viewport 메타, 전체 레이아웃 |
| `app` | `manage/layout.tsx` | Admin 레이아웃 (사이드바/햄버거 분기) |
| `widgets` | `Header` | 반응형 헤더 (세로 ↔ 가로) |
| `widgets` | `Footer` | 반응형 푸터 |
| `widgets` | `AdminSidebar` | 데스크톱 사이드바 + 모바일 오버레이 |
| `shared` | `Pagination` | 반응형 페이지네이션 (표시 범위 분기) |

## 수용 기준

- [ ] 320px 뷰포트에서 가로 스크롤 없이 레이아웃이 정상 표시된다
- [ ] 브레이크포인트 3개(480px, 768px, 1080px)에서 레이아웃이 적절히 전환된다
- [ ] 헤더가 모바일에서 세로 스택, md 이상에서 가로 배치된다
- [ ] Admin 사이드바가 모바일에서 햄버거 메뉴로 접히고, 오버레이로 열린다
- [ ] 오버레이 외부 클릭 시 사이드바가 닫힌다
- [ ] 글 리스트 썸네일이 모바일에서 숨겨지고 md 이상에서 표시된다
- [ ] 페이지네이션이 모바일에서 +-1, md 이상에서 +-3 범위로 표시된다
- [ ] heading-xl/lg가 모바일에서 한 단계 축소된다
- [ ] 본문 이미지가 `max-width: 100%`로 뷰포트를 초과하지 않는다
- [ ] 마크다운 테이블이 뷰포트 초과 시 가로 스크롤된다
- [ ] 콘텐츠 영역 최대 폭이 `max-w-[67.5rem]`(1080px)이다
- [ ] 접근성: 반응형 전환 시 포커스 상태가 유지된다 (A-01 참조)

## 에지 케이스

| 케이스 | 처리 |
|---|---|
| 320px 미만 뷰포트 | 지원 범위 외. 가로 스크롤 발생 가능 |
| 매우 긴 단어 (URL 등) | `overflow-wrap: break-word`로 줄바꿈 |
| Admin 사이드바 열린 상태에서 화면 회전 | md 이상이면 오버레이 자동 닫힘, 사이드바 고정 표시 |
| Admin 사이드바 열린 상태에서 뒤로가기 | 오버레이 닫힘 처리 |
