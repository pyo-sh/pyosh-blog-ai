# Admin Dashboard Design

**Date:** 2026-03-14
**Area:** client
**Issue:** client #43

## Goal

`/dashboard`를 관리자 홈 화면이자 상세 통계 페이지 진입 화면으로 구현한다. 첫 화면에서 핵심 지표를 빠르게 확인하고, 최신 댓글 확인과 주요 관리 화면 이동을 쉽게 만드는 것이 목적이다.

## Scope

- 통계 카드 5개 표시
- `상세 통계 보기` 단일 CTA 제공
- `최신 댓글` 읽기 전용 섹션 제공
- `빠른 이동` 링크/액션 섹션 제공
- 로딩 스켈레톤 및 반응형 그리드 구현

## Layout

### 1. Stats Summary

페이지 상단은 통계 카드 5개로 시작한다.

- 오늘 조회수
- 주간 조회수
- 월간 조회수
- 총 게시글
- 총 댓글

카드는 작은 화면에서 2열, 중간 화면에서 3열, 큰 화면에서 5열로 배치한다. 통계 영역에는 상세 통계 페이지로 이동하는 `상세 통계 보기` CTA를 1개 둔다.

### 2. Recent Comments

통계 영역 아래에는 `최신 댓글` 섹션을 둔다. 이 섹션은 홈 화면에서 최근 반응을 빠르게 훑어보는 목적이며, 읽기 전용 목록으로 유지한다. 각 항목은 작성자, 대상 게시글, 작성 시각 중심으로 간단히 표시하고, 클릭 시 관련 관리 화면으로 이동할 수 있게 한다.

### 3. Quick Actions

`빠른 이동` 섹션은 관리 목록 이동과 즉시 액션 진입을 혼합한다. 예시는 다음과 같다.

- 게시글 관리
- 댓글 관리
- 카테고리 관리
- 새 글 작성

모바일에서는 보조 섹션을 세로 적층하고, 넓은 화면에서는 `최신 댓글`과 `빠른 이동`을 2열로 배치한다.

## Data Strategy

### Stats

통계 카드 5개는 실데이터를 사용한다. 기존 TanStack Query 패턴을 따르며, 통계 로딩 중에는 카드 스켈레톤을 노출한다.

### Recent Comments

최신 댓글 API가 준비되지 않았으면 샘플 데이터를 사용한다. 단, 섹션에는 `샘플 데이터` 또는 `준비 중` 배지를 명시해 실제 운영 데이터로 오인하지 않게 한다. 이후 실제 API로 쉽게 교체할 수 있도록 데이터 형태는 목록 인터페이스 기준으로 분리한다.

### Quick Actions

빠른 이동 섹션은 정적 링크/액션 구성을 사용한다.

## Error Handling

- 통계 로딩 실패는 통계 섹션 단위에서 안내한다.
- 전체 페이지 실패로 확장하지 않는다.
- 최신 댓글이 샘플 데이터일 경우 별도 오류 처리는 단순화한다.

## Architecture Notes

- 페이지 조립은 `src/app/dashboard/page.tsx`에서 시작한다.
- 기존 entity/feature 계층의 API, 타입, UI를 최대한 재사용한다.
- 새 UI 조각이 필요하면 FSD import 방향 `app -> widgets -> features -> entities -> shared`를 지킨다.
- 이번 이슈 범위에는 상세 통계 페이지 자체 구현은 포함하지 않는다. 진입 CTA만 제공한다.
